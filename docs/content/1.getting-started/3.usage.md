This module exposes composables that are [auto-imported](https://nuxt.com/docs/guide/directory-structure/composables#composables-directory) by Nuxt 3.

For more details check out the official documentation of initializing Algolia client [here](https://www.algolia.com/doc/api-client/getting-started/instantiate-client-index/javascript/?client=javascript).

## `useAlgoliaSearch`

Use this composable to search the index by certain query and optional request options.

### Client-side usage

```vue [pages/search.vue]
<script setup>
const { result, search } = useAlgoliaSearch('test_index')

onMounted(async () => {
  await search({ query: 'Samsung' })
})
</script>

<template>
  <div>{{ result }}</div>
</template>
```

### Server-side usage (SSR)

This composable also works for SSR applications:

```vue [pages/search.vue]
<script setup lang="ts">
const { result, search } = useAlgoliaSearch('test_index')

const { data } = await useAsyncData('ssr-search-results', () => 
  search({ query: 'Samsung' })
)
</script>
```

### Return values

- **`result`**: A reactive computed property containing the search results. The result format is described [here](https://www.algolia.com/doc/api-reference/api-methods/search/#response).
- **`search`**: Method used to fetch results from the index. It requires a `query` parameter and accepts optional `requestOptions` that you can check out [here](https://www.algolia.com/doc/api-reference/api-methods/search/#method-param-requestoptions).

For more details check out the official documentation of this method [here](https://www.algolia.com/doc/api-client/methods/search/).

## `useAsyncAlgoliaSearch`

Async wrapper around `useAlgoliaSearch` composable that decreases the number of steps needed to use Algolia with `useAsyncData` while maintaining the same functionality. The response will have a form described [here](https://www.algolia.com/doc/api-reference/api-methods/search/#response) and will be wrapped around `useAsyncData` so you will have access to `data`, `error`, and other properties.

```vue [pages/search.vue]
<script setup lang="ts">
const { data, error } = await useAsyncAlgoliaSearch({ 
  indexName: 'test_index', 
  query: 'Samsung' 
})
</script>

<template>
  <div>{{ data.value.hits }}</div>
</template>
```

### Parameters

This composable accepts an object with the following properties:

- **`indexName`**: The name of your index in Algolia dashboard. For more details about initializing index check out the official documentation [here](https://www.algolia.com/doc/api-client/getting-started/instantiate-client-index/javascript/?client=javascript#initialize-an-index). If you passed a global index in your module configuration, this property can be skipped.
- **`query`**: A keyword, sentence, or text that you want to search the index with.
- **`key`**: If you need multiple `useAsyncAlgoliaSearch` calls in a single page, add a unique key to get passed to the `useAsyncData` underneath, so new calls won't overwrite old data.
- **`requestOptions`**: Optional object with options for the request like filters. You can check more about it [here](https://www.algolia.com/doc/api-reference/api-methods/search/#method-param-requestoptions).

### Filtering by facets

If you want to fetch search results filtered by some facet values:

```ts
const { result, search } = useAlgoliaSearch("INDEX_NAME")

await search({ 
  query: input_string, 
  requestOptions: {
    facetFilters: ["tags:happy"] 
  } 
})
```

## `useAlgoliaInitIndex`

Use this composable to initialize index you would like to search through. It accepts an index name as a parameter and returns an object with a `search` method.

```vue
<script setup>
const { search } = useAlgoliaInitIndex('test_index')

onMounted(async () => {
  const result = await search('Samsung')
  console.log(result)
})
</script>
```

For more details about search method check out the official documentation [here](https://www.algolia.com/doc/api-client/methods/search/)

## `useAlgoliaFacetedSearch`

Use this composable to search using facet values like `category`, `phone`.

::alert{type="info" icon="i-ph-info"}
In order for this to work, you have to:
1. Set `lite: false` in your `algolia` configuration in `nuxt.config.ts`.
2. Add facet attributes in your dashboard or via code. Read more about it [here](https://www.algolia.com/doc/guides/managing-results/refine-results/faceting/).
::

```vue
<script setup>
const { result, search } = useAlgoliaFacetedSearch('test_index')

onMounted(async () => {
  const facet = { 
    name: 'category',
    query: 'phone'
   }
  await search({ facet })
})
</script>
```


## `useAlgoliaRecommend`

Use this composable to get the recommendations matching certain criteria with optional request options.

::alert{type="info" icon="i-ph-sparkle"}
In order to make this composable work, make sure to set the `recommend` property to `true` in your Algolia configuration in `nuxt.config.ts`.
::

```vue
<script setup>
const { result, get } = useAlgoliaRecommend()

onMounted(async () => {
  await get({ queries: [{ indexName: 'test_index', model: 'related-products', objectID: 'dca44dd5-aea6-4553-a3af-fcbda981a2ef' }] });
})
</script>
```
### Return values

- **`result`**: A reactive computed property containing the recommendations. The result format is described [here](https://www.algolia.com/doc/api-reference/api-methods/get-recommendations/#response).
- **`get`**: Method used to get the recommendations based on the criteria described [here](https://www.algolia.com/doc/api-reference/api-methods/get-recommendations/#parameters) and an optional parameter of `requestOptions` that you can check out [here](https://www.algolia.com/doc/api-reference/api-methods/search/#method-param-requestoptions).

### Optional parameters

- **`key`**: If you need multiple `useAlgoliaRecommend` calls, add a unique key to get passed to the `userState('recommend-result')` underneath, so new calls won't overwrite old data.

For more details check out the official documentation of this method [here](https://www.algolia.com/doc/api-reference/api-methods/get-recommendations/).

## `useAlgoliaRef`

By calling this composable you have access to the `algoliasearch` instance anywhere in your app.

```vue [composables/useAlgolia.ts]
<script setup>
const algolia = useAlgoliaRef()
</script>
```

This is useful when you need direct access to the Algolia client for advanced use cases.
